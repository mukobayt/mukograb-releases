# MukoGrab İndirme Yöneticisi

Windows 10/11 için ücretsiz, reklamsız indirme yöneticisi — **Dev. MUKO**

- IDM tarzı çok parçalı, hızlı indirme; kaldığı yerden devam
- Video yakalama (tarayıcı uzantısıyla), HLS yayınları
- BitTorrent: magnet bağlantıları ve .torrent dosyaları
- Türkçe ve İngilizce arayüz

## İndir

En son sürüm: **[Releases](https://github.com/mukobayt/mukograb-releases/releases/latest)** sayfasından `MukoGrab-Setup.exe` dosyasını indirip çalıştırın.

Kurulumdan sonra MukoGrab güncellemeleri kendisi bulur ve sorar; her güncelleme kurulmadan önce SHA-256 ile doğrulanır.

## Kullanım şartları

MukoGrab ücretsizdir; kaynak kodu açık değildir. Kurulum dosyasını değiştirmeden paylaşabilirsiniz.
İndirdiğiniz içeriğin ve kullanımının sorumluluğu size aittir. Kullandığı açık kaynak bileşenlerin
lisansları programın "Hakkında" bölümünde yer alır.

# MukoGrab Download Manager

Free, ad-free download manager for Windows 10/11. Download the latest `MukoGrab-Setup.exe` from
[Releases](https://github.com/mukobayt/mukograb-releases/releases/latest). MukoGrab finds updates itself
and verifies each one (SHA-256) before installing. You are responsible for what you download.
